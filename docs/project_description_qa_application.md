# Описание проекта для анкеты QA Fullstack

## Вопрос 12: Расскажите про ваш самый интересный проект

Моим самым интересным проектом является pet-проект "Project-X" — интеллектуальный новостной агрегатор на базе Telegram. Проект представляет собой полноценную распределённую систему, которая автоматически собирает, анализирует и синтезирует новости из множества телеграм-каналов с использованием AI.

Техническая реализация включает: асинхронную архитектуру на Python (asyncio), интеграцию двух Telegram-клиентов (Telethon для парсинга + Aiogram для бота), машинное обучение для кластеризации новостей (sentence-transformers, sklearn), AI-классификатор рекламы и генерацию контента через OpenAI API. Система использует PostgreSQL с embedding-векторами для семантического поиска, реализует автоматическую репутационную систему для источников и мониторинг engagement-метрик постов.

С точки зрения QA проект интересен комплексностью тестирования: требуется покрытие API-интеграций (Telegram Bot API, OpenAI), асинхронных процессов, работы с базой данных, ML-моделей и их точности, а также edge-cases в парсинге и обработке контента. Я настроил CI/CD с автоматическими проверками, логированием через YAML-конфиги и систему обработки ошибок с экспоненциальными retry-механизмами. Проект научил меня не только разработке, но и подходам к тестированию сложных распределённых систем с внешними зависимостями.

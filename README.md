# Telegram News Parser Bot

Умный бот для персонализированной подборки новостей из Telegram-каналов. Бот анализирует новости, фильтрует их по интересам пользователя, исключает дубликаты и предлагает "горячие" новости, которые могут быть интересны пользователю.

## Возможности

- 📰 Автоматический парсинг новостей из Telegram-каналов
- 🎯 Персонализированная фильтрация новостей по интересам пользователя
- 🔄 Автоматическое определение и исключение дубликатов
- 🔥 Рекомендация "горячих" новостей
- ⚙️ Гибкая настройка предпочтений пользователя
- 📊 Статистика и аналитика по новостям

## Требования

- Python 3.8+
- PostgreSQL 12+
- Telegram API credentials (api_id и api_hash)

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/telegram-news-parser-bot.git
cd telegram-news-parser-bot
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для Linux/Mac:
source .venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Создайте файл конфигурации:
```bash
cp config/config.example.py config/config.py
```

5. Отредактируйте `config/config.py`, добавив необходимые учетные данные:
- Telegram API credentials (api_id и api_hash)
- Настройки базы данных
- Параметры бота

6. Создайте базу данных:
```bash
# Подключитесь к PostgreSQL и создайте базу данных
createdb telegram_news_bot
```

## Запуск

1. Активируйте виртуальное окружение (если еще не активировано):
```bash
# Для Windows:
.venv\Scripts\activate
# Для Linux/Mac:
source .venv/bin/activate
```

2. Запустите бота:
```bash
python main.py
```

## Использование

### Команды бота

- `/start` - Начало работы с ботом
- `/help` - Получить справку по командам
- `/settings` - Настройка предпочтений
- `/news` - Получить последние новости
- `/hot` - Показать горячие новости
- `/stats` - Показать статистику

### Настройка предпочтений

1. Используйте команду `/settings`
2. Выберите интересующие вас категории новостей
3. Настройте частоту получения новостей
4. Установите предпочтительные источники
